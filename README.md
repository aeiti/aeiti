network, and show-control systems in live theatre, at Tuacahn, Cirque du Soleil,
PRG, South Coast Repertory, and currently Pasadena Playhouse. For the last
stretch of it I've been building the software I kept wishing the job came with.

Most of what's here started as a tool I needed. A few of them other people use now.

## Things worth looking at

**[palmon-guild-manager](https://github.com/aeiti/palmon-guild-manager)**
Full-stack guild management app. Next.js 16, React 19, TypeScript, Postgres via
Drizzle ORM on Neon, Discord OAuth through Auth.js, role-gated in middleware.
History tables are append-only, so the trend views read back real history rather
than reconstructing it.

**[palmon-tools](https://github.com/aeiti/palmon-tools)**
Calculators and trackers for *Palmon: Survival* players, live at
[aeiti.github.io/palmon-tools](https://aeiti.github.io/palmon-tools/). React,
Vite, and Tailwind, with tagged releases deployed by GitHub Actions. Everything
stays in your browser; nothing is sent to a server.

**[kato8-staging](https://github.com/aeiti/kato8-staging)**
The React application behind kato8studios.com, where I intern. I wrote its Vite
build pipeline: a prerender pass so client-routed pages are crawlable,
responsive image-variant generation, and unused-asset auditing. It also has a
component preview harness with a documented registry, kept out of the prerender
and SEO config so preview routes stay unindexed.

**[kato8-newsletter-api](https://github.com/aeiti/kato8-newsletter-api)**
Netlify Functions service backing newsletter signup on the same site, persisting
to Turso.

**[Pokemon-Red-AI](https://github.com/aeiti/Pokemon-Red-AI)**
Behavioral cloning and reinforcement learning agent that plays Pokémon Red, in
Python. The v1 milestone is beating Brock.

**[portfolio](https://github.com/aeiti/portfolio)**
My lighting design portfolio, built with Astro and deployed to GitHub Pages.
[aeiti.github.io/portfolio](https://aeiti.github.io/portfolio/)
